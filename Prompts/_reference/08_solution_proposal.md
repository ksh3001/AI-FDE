# Prompt 08 — Final Solution Proposal

Produce an executive and engineering proposal that includes:

- evidence-backed problem statement;
- target operating workflow;
- measurable outcomes;
- domain ownership;
- target architecture;
- key decisions and trade-offs;
- safety, environmental, security and governance controls;
- data and integration strategy;
- human adoption and operating model;
- phased roadmap;
- delivery assumptions;
- residual risks;
- sponsor decisions required.

Clearly distinguish the participant prototype from a production `{DOMAIN}` system.

Write to `participant-outputs/08-proposal/{SYSTEM}_solution_proposal.md`.
