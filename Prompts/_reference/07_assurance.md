# Prompt 07 — Assurance

Audit the completed application.

Assess:

- data-contract handling;
- identifier and timestamp behavior;
- conflict and freshness visibility;
- deterministic behavior where claimed;
- explainability;
- authority and prohibited-language controls;
- privacy;
- security and remote-access handling;
- degraded-mode operation;
- critical user workflows;
- performance;
- false-positive and false-negative examples;
- architecture-to-code consistency;
- ADR implementation;
- residual risk.

Write to `participant-outputs/07-evaluation/evaluation_report.md`.
