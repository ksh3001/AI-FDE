# Prompt 02 — SCQA

Create an evidence-backed SCQA (Situation · Complication · Question · Answer) decision narrative.

Requirements:

- establish normal `{DOMAIN}` operations and desired outcomes (Situation);
- describe the compound complication across the relevant dimensions (e.g. operational, technical, people, resource, environmental, commercial, security and data);
- formulate one bounded decision or engineering question (`{DECISION_PROBLEM}`);
- define user, decision horizon, evidence boundary and authority boundary;
- propose a capability-level answer without preselecting architecture;
- define measurable outcomes and explicit exclusions.

Write to `participant-outputs/02-scqa/scqa_decision_narrative.md`.
