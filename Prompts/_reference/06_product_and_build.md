# Prompt 06 — Product Definition and Build

Using approved SCQA, DDD, C4 and ADR artifacts:

1. define the primary user journey;
2. create a prioritized product backlog;
3. define data contracts;
4. define explanation and uncertainty behavior;
5. implement the application in the selected stack;
6. add tests before major refactoring;
7. prohibit operational write-back (`{PROHIBITED_ACTIONS}`);
8. keep specialist authority visible;
9. update the traceability matrix.

Do not hard-code conclusions for specific entities or cases.
