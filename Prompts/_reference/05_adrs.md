# Prompt 05 — ADRs

Create at least five architectural decision records.

Consider decisions involving:

- entity, process and event identity;
- source-event time and report time;
- canonical models and source translation;
- rules, analytics and explainability;
- data persistence and evidence snapshots;
- online, intermittent and offline operation;
- role and authority enforcement;
- decision audit;
- external integrations;
- deployment and observability.

For each decision, include alternatives, drivers, consequences, guardrails, validation and revisit triggers.

Write to `participant-outputs/05-adrs/`.
